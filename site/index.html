The missing step

Fast code is not the same as a working animation.

AI can write a scene in seconds. It cannot tell you if a state is missing, a property is on the wrong object, or the file breaks in the real Rive player. rive-cli turns those unknowns into checks you can run again.

Made for the tool loop

Give your agent an answer it can act on.

A picture helps a person. A measured result helps a tool. The CLI reports object counts, missing types, pixel changes, content bounds, and a simple coverage map.

Start with a terminal

One small loop. Fewer surprises.

# install from this repo
$ cargo install --path .

# make, build, and check a scene
$ rive-cli new spinner > scene.json
$ rive-cli generate scene.json -o scene.riv
$ rive-cli validate scene.riv
$ rive-cli render scene.riv --preview

Need a field name or a valid parent? Ask the tool. describe and schema list the things you can make, so your agent does not have to guess.
