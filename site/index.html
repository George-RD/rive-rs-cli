rive-cli

Rive animations, compiled from JSON.

A command-line compiler for the Rive binary format. Write a scene as JSON, get a .riv. Then render it, measure it, and prove it works — no editor, no runtime in the loop you cannot inspect.

See what it makes See how it is proved

Every animation on this page is a .riv file this tool produced. Not a video, not a GIF — the same committed binaries the test suite loads, playing live in the Rive WebAssembly runtime in your browser. Six of them were authored end to end by an AI agent given nothing but one skill file and one binary; four more were added to demonstrate embedded fonts, path morphing, embedded imagery and pointer-driven state machines. All ten clear the same measured gate on every commit.

How it is verified

The compiler is only half of it. An agent cannot look at a picture, so the tool measures its own output: distinct colours, a dominant-colour ratio, a content bounding box, and an ASCII coverage map. This transcript is copied verbatim from a real run.

Three layers guard every scene on this page: generate and validate in the Rust integration suite, a real-runtime load in headless Chromium, and pixel baselines at three frames each. Interaction is proved separately by rendering the same frames with and without a pointer event and requiring the frames before it to be byte-identical.

Quickstart

$ cargo install --path .
$ rive-cli new spinner > scene.json
$ rive-cli generate scene.json -o scene.riv
$ rive-cli validate scene.riv
$ rive-cli render scene.riv --frames 0,30,60 --preview -o frames/

rive-cli describe <type> reports the fields, valid parents and animatable properties of any of the ~200 object types, and rive-cli schema emits the full JSON Schema for a scene.
